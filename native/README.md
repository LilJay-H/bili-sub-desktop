# Windows 透明桌面字幕辅助程序

v0.7 使用全局字幕窗口：顶部时间居中、加粗并以青绿色强调；紧凑控制栏配备拖动进度条，空闲时保留底部2px进度线。点击字幕区后支持空格播放暂停、左右键快进快退。

WPF 的 `AllowsTransparency` 和无边框置顶窗口提供真正的桌面透明背景，文字保持独立不透明。它使用系统自带 .NET Framework（本机 4.8）编译，无下载依赖、无联网、无监听端口。

## 安装一次

1. 推荐双击项目根目录的 `一键安装器.cmd`，它会登记助手并打开扩展管理页。也可以先在 Chrome / Edge 扩展管理页加载或重新加载本扩展。
2. 若手动安装，双击本目录 `Install.cmd`，自动识别固定扩展 ID，无需输入。仅在当前用户 HKCU 登记本工具的 Native Messaging 宿主，无需管理员权限。
3. 重新加载扩展，刷新 B 站视频页，全局字幕自动打开。

脚本从项目 manifest 公钥计算固定 ID，写入本目录 `com.bilisub.desktop.json`，并兼容原清单中最多两个严格合法的旧 ID。不扫描浏览器资料，不允许通配符。Chrome 与 Edge 新加载此版本使用相同固定 ID；目录须保留，移动后再次双击安装脚本。升级步骤与验证范围见 [免 ID 安装说明](../docs/INSTALL-v0.6.md)。

`Uninstall.cmd` 删除本工具在 Chrome / Edge 中的宿主登记，不删除其他设置。窗口位置和大小仅保存在 `%LOCALAPPDATA%/BiliSubDesktop/window.json`。

## 使用

- 默认 760 × 192，鼠标移开后顶部2px、底部3px留白，底部保留2px进度线。
- 移入显示拖动栏、控制栏和边框，字幕暂时避让；移开立刻恢复全框阅读。拖顶部移动，拖四边/四角缩放，松开后保存几何。
- 外观分开调整「窗口透明度」与「字幕底色」：新默认窗口100%透明、字幕底色90%不透明，已有窗口透明度偏好继续保留。窗口100%时保留1/255 alpha命中层，肉眼透明，仍能让鼠标移入唤出控制。
- 字幕底色按每行文字长度包底，约2px内衬；空白区域不铺底。统一几何一次绘制，句子交叠处不会加深透明度，DOM当前句也有相同底色。
- 文字不会随两种透明度变淡。当前句仅用赭红（深色为浅赭红）下划线标记，点击字幕跳转。滚轮阅读暂停自动跟随，点「跟随播放」恢复。
- 字幕按连续文本换行，长句不省略。协议每句最多 5000 字符，与扩展字幕规范化上限一致。
- 倍速按钮打开同窗口内网格，支持 0.25～4 倍；收到播放器实际状态后才更新选中值，持续播放进度不会关闭选择面板。
- 外观设置可切换「连续文本 / 逐句换行」，保留每句起止时间、高亮与点击跳转。宽窗双栏、窄窗单栏，滚动设置内容时返回按钮保持可见。
- 「×」关闭全局窗口；网页只保留重新打开的按钮。Escape 返回字幕或收起工具，Tab 可以访问控制。原网页要保持打开。
- 外观设置可以调整快进步长。点击字幕区后，空格播放暂停，左右键按步长跳转；进度条与设置控件保留自己的键盘操作。
- 设置底部折叠调试区显示来源、当前窗口内句数、时间和局部索引。

## 本地编译与验证

`powershell -NoProfile -ExecutionPolicy Bypass -File native/Build.ps1` 重新生成 `BiliSubDesktop.exe`。脚本以 UTF-8 BOM 保存，兼容 Windows PowerShell 5。

`node native/Test.cjs` 在离屏位置创建本工具窗口，不读取或截图桌面、不连接浏览器、不登记宿主。测试覆盖：

- 真实 HWND 具有 layered 和 topmost 扩展样式。
- 透明背景输出像素 alpha=1，文字前景 alpha=255。
- 192px 窗口里空闲字幕可用高184px；控件显示时避让至114px，收起恢复184px。
- 1600字长句完整换行、从开头展示，排版定位与实际文字高度一致。
- 当前句自动定位、手动阅读不被抢滚动。
- 播放、倍速、字号控件发出对应命令。
- stdin/stdout 4字节小端长度 + UTF-8 JSON 协议：分片读取、ready、state、close、closed、干净退出。
- 同窗口倍速面板经过连续8次播放状态更新仍保持打开；设置选择以播放器回传为准。
- 连续 / 逐句排版实际内容高度不同，起止时间与点击跳转保留；760×192、360×160设置布局可访问全部选项。
- 设置面板为不透明背景；150%自有窗口渲染无裁切（不等同于更改操作系统显示缩放的实测）。
- v0.6实际像素：90%字幕底色alpha=230，50%为128，窗口空白为1；普通句、当前句、DOM当前句同样覆盖。单次绘制的底色最高alpha为230，不因相邻句内衬交叠加深。
- 自动跟随保证可容纳的当前句完整可见；超过视口的长句从开头显示。上下文边缘与手动滚动仍允许部分行经过边界。

发现并修复了 WPF TextBlock 的 Hyperlink TextPointer 在跨行文本中退化到句尾的问题。当前使用相同字体、行距和宽度的 FormattedText 几何定位，缓存布局以避免每次进度更新重复计算。
