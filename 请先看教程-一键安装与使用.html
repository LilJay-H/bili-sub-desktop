这是解压后应该首先打开的教程文件。请先看完，再运行同目录的「一键安装器.cmd」。

把字幕
放到桌面上。

用四个步骤，把 B 站视频字幕变成一块透明、置顶、可以随手调整的桌面阅读卡。

先读这一页 安装不需要复制扩展 ID。
透明置顶需要 Windows 原生助手。
原视频页面需要保持打开。
01

完整解压

把整个压缩包解压到准备长期保留的文件夹，不要只拎出一个文件。

02

一键登记

双击同目录的「一键安装器.cmd」，它会自动登记透明桌面助手。

03

加载扩展

在 Chrome 或 Edge 的扩展管理页，点击「加载已解压的扩展程序」。

04

刷新 B 站

选择当前文件夹，刷新视频页，点「桌面置顶」即可开始使用。

QUICK START / 快速开始

一次安装，之后直接使用

  1. 确认这个文件夹里能看到 manifest.json、native 和本教程。
  2. 双击根目录的 一键安装器.cmd。它会自动识别 Chrome 或 Edge，并打开扩展管理页。
  3. 在扩展管理页打开「开发者模式」，点击「加载已解压的扩展程序」，选中当前文件夹。
  4. 回到 B 站视频页并刷新。视频有可读取字幕时，点击页面中的「桌面置顶」。
不需要填写 ID。 安装器会从随包公钥自动得到固定扩展 ID，并在当前用户下登记 Chrome / Edge 的 Native Messaging 宿主。
打开 Chrome 扩展管理页 打开 Edge 扩展管理页

你会看到什么

  • 字幕文字有局部底色，空白区域透明。
  • 当前句用下划线标记。
  • 鼠标移开后，字幕占满整个窗口。
  • 窗口可以拖动、缩放、调透明度和倍速。

出了问题？

桌面助手未连接：重新双击「一键安装器.cmd」，再重新加载扩展并刷新 B 站。

没有字幕：画面烧录文字无法读取，请确认播放器里有 CC/字幕。

移动过文件夹：再运行一次安装器，让系统更新助手路径。

隐私边界

扩展不读取 Cookie，不申请 cookies 权限，不保存登录凭证。助手不联网、不监听端口，只接收当前 B 站页面的播放与字幕消息。
