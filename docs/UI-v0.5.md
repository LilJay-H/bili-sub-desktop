# v0.5：杂志阅读界面与桌面交互修复

## 设计依据

使用 ui-ux-pro-max，style 检索命中 **Editorial Grid / Magazine**；typography 检索命中 **Magazine Style / Serif + Sans**。采用编辑网格、印刷字体层级、细分隔线和克制的强调色。没有引入远程字体或新依赖：标题使用本机 Georgia / 宋体，正文与控件使用清晰的无衬线字体。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 纸面/面板 | #F7F4ED | #1E1D1A |
| 正文 | #25231F | #F2EDE2 |
| 辅助文字 | #716C62 | #B6AEA0 |
| 强调 | #9A4938 | #E7B69C |
| 分隔 | #D6D0C4 | #49443C |

字幕背景仍可透明；设置面板使用实色，避免底下字幕干扰。空闲时控件全部隐藏且不占字幕空间。布局以紧凑桌面阅读为准，未照搬网页大标题、首字下沉或装饰图片。

## 行为变化

- 桌面倍速改为窗口内面板，不使用独立 Popup 下拉框；点击具体倍速发送播放命令。
- 原生窗口旧代码会在鼠标离开主窗口时隐藏控制，也在每次状态更新时重设 ComboBox 选中值。这是代码中确认的风险点；用户现场故障未被录制，因此不将单一触发原因表述为已实测复现。
- 设置固定标题与返回入口，内容独立滚动；宽窗双栏、窄窗单栏。
- 排版有「连续文本」「逐句换行」，页内与桌面双向同步，刷新保留。切换只改变句间分隔，不改变原字幕起止时间、点击跳转或命中逻辑。
- 原生透明、置顶、拖动缩放和鼠标移开后全框字幕继续保留。

## 已验证

- JavaScript 共38项测试通过，包含原播放器模块与新增四层串联：原生命令 → 后台白名单 → 隔离世界 → 主世界播放器 setter → 状态回显。1.5×、2×、0.75×、1×与连续 timeupdate 交错时保持正确倍速。
- layout 的双向同步、单独 layout 命令、非法枚举拒绝以及偏好保存通过。
- 独立 Chrome 离线渲染通过：实色设置面板、固定标题、内容滚动、逐句换行、375px无横向溢出、全框字幕与拖拽回归。
- 浏览器截图：evidence/ui-v5-*.png；检查值：evidence/ui-v5-checks.json。截图为假字幕。
- 原生自测与协议回环通过：倍速面板经历8次状态更新仍打开，实际回显1.5×；短句样本连续排版内容高86.4px，逐句换行115.2px，句尾时间与点击跳转保留。
- 原生设置背景alpha=255，360×160时单栏可滚动访问所有项；150%自绘检查通过。192px窗高下，悬停字幕区114px，移开恢复184px，不留控件占位。
- 原生窗口的最新视觉与交互结果见 evidence/native-v5-* 与 native/Test.cjs；只渲染工具自己的离屏窗口。

没有读取用户其他应用或登录凭证，没有替用户修改浏览器权限或本机注册项。安装后的 B 站真实播放与跨应用体验仍需复验，不能把离线测试等同于这部分验收。

## 更新后检查

1. 关闭旧桌面字幕窗口，更新扩展及助手文件；重新加载扩展、刷新视频页后重开桌面置顶。
2. 打开倍速面板，连续播放时选择1.5×、2×和1×，与B站播放器核对。
3. 打开外观：两栏字段不重叠，窄窗可以滚动；返回标题始终可达。
4. 切换连续文本／逐句换行：当前句和点击跳转保持，返回页内后排版一致。
5. 鼠标移开后无控制栏占位，透明度、拖动缩放仍正常。
