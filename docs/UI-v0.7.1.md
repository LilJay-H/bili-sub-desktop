# v0.7.1 交互更新与验证

## 本次更新

- 悬停工具栏覆盖在字幕上方，字幕视口、换行和滚动位置保持不变。
- 点击字幕区后，↑ / ↓ 调节 10 个百分点音量，范围 0%–100%；静音时按 ↑ 从 10% 恢复声音。
- 顶部横栏左、中、右空白区域及底部横栏空白区域均可拖动窗口。按钮、进度条执行各自操作，外沿继续缩放。
- 右侧自绘滚动条不占排版宽度：灰色轨道与暖橙色滑块默认 2px，轨道悬停均为 4px，滑块悬停为 7px 且上下各延伸 2px。
- 滚动条支持拖动和点击轨道，手动浏览后可点“跟随播放”恢复跟随。

## 已验证

2026-10-29，Windows 本地测试。

- `node --test tests/*.test.js`：42 项通过，包括音量命令从桌面桥经后台到播放器的四层集成、音量上下界、静音、非法值拦截。
- `node native/Test.cjs`：WPF 离屏渲染、真实窗口样式、消息协议通过。
- 8 组悬停稳定性场景：760 / 360px 宽、连续 / 逐句排版、自动跟随 / 手动滚动，分别反复显隐 6 次并交错播放状态更新。字幕宽高、当前句坐标、滚动偏移均不变。192px 高窗口的字幕视口始终为 187px。
- WPF 键盘路由事件验证空格、左右键、上下键；设置滑块不发送播放快捷键。
- 实际布局命中检查覆盖顶部左中右、底部两侧、上下边缘缩放；按钮和播放进度条不触发移动。
- 滚动条三种线宽、滑块拖动、上下边界、设置打开与鼠标移出时隐藏通过。
