- 用户约束禁止操作/截图其他应用，因此没有切换无关应用或拍摄整屏。跨应用置顶和后台 60 秒由用户按清单完成。
- 未提供人工字幕和分P样本；没有验证未登录时 AI 字幕是否可读，不主动退出登录作对照。
- DOM 当前句选择器仅离线测试；普通 window.open 降级、刷新时 PiP 生命周期尚未真机验收。

## 假设与设计取舍

1. 以桌面 Chromium 116+ 为目标；Edge 和 macOS 属于兼容性预期，不是实测结论。
2. 默认选择中文，人工中文优先于 AI 中文；暂不提供语言菜单。
3. 只把有时间轴的字幕 JSON 或网站字幕 DOM 视为字幕，不解析画面文字。
4. 上下集先使用普通导航保证目标明确，接受 PiP 需要重开的降级。
5. 缓存为有容量上限的内存缓存，刷新/进程回收后可能重新请求。
6. 播放器接口实际为同站跨源；不虚构严格同源接口，不读取账号凭证。
7. 人工字幕其他域名未实测，不加入扩展权限；可以复用网站自然请求，否则明确降级。
