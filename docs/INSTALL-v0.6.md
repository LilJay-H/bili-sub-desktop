# v0.6 免填写扩展 ID 安装

扩展现在使用固定公钥，所以 Chrome / Edge 新加载的扩展 ID 固定为 `bmahpadepgddfgapdlkebjhcebieednd`，不随文件夹路径改变。此 ID 不是账号或登录凭证。

1. 完整解压到准备长期保留的文件夹，先打开根目录的 `请先看教程-一键安装与使用.html`。
2. 双击根目录的 `一键安装器.cmd`。它会自动登记助手并打开 Chrome / Edge 扩展管理页。
3. 在扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择当前文件夹。
4. 刷新 B 站视频页，点击「桌面置顶」。安装器可以重复双击运行。

已有开发者版本先重新加载扩展，再试连接。安装器会兼容本文件夹原有宿主清单中最多两个合法旧 ID。如果旧实例仍未切换为固定 ID 且无法连接，可移除旧扩展后重新加载原文件夹一次；本工具外观偏好保存在 B 站页面的专用 localStorage 键中，不会因为扩展 ID 改变而删除。

安装器只读取本项目的 `manifest.json` 和 `native/com.bilisub.desktop.json`，不会扫描浏览器资料或其他扩展。它根据公钥自动计算 ID，写入本工具宿主清单及当前用户 Chrome / Edge 的两个 Native Messaging 登记项。允许来源为当前固定 ID 加最多两个严格合法旧 ID，不使用通配符。

缺失或格式损坏的公钥会在写文件、登记或编译前报错。请使用完整版本，不自行编辑 `manifest.key`。

验证范围：测试在真实 Windows PowerShell 5 中运行，注册表命令被模拟；验证无需输入、路径无关的固定 ID、坏 key 提前失败及旧 ID 严格过滤。一键安装器的浏览器打开逻辑已做脚本解析检查，没有在测试中修改用户真实注册表，也没有扫描浏览器资料。实际新扩展加载和真实 Native Messaging 连接仍需用户按以上步骤完成。
