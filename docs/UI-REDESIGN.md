# v0.2 UI 重构

> 本文保留 v0.2 历史记录。当前 v0.3 的拖动缩放、连续阅读、配色和验证结果见 [UI-v0.3.md](UI-v0.3.md)。

使用 `ui-ux-pro-max` 技能检索设计系统和 style / ux 数据库。整体推荐混有落地页、超大标题与营销配色，不适合桌面字幕；选用进一步检索得到的 **Minimalism & Swiss Style**，保留清晰字级、单色、极少装饰、180ms 淡入淡出。原生 JS/CSS，无框架、外链字体或图标库。

| 用户反馈 | 修改 |
| --- | --- |
| UI 杂乱 | 去掉品牌块、卡片标题、装饰色、常驻提示，使用一致细线 SVG 图标和白色当前句 |
| 看不到透明度修改 | 外观设置直接放置「背景透明度」0～100% 滑块，默认 85%；值越大越透明，字号/透明度/步长保存在本工具专用本地键 |
| 非字幕内容常驻遮挡 | 顶栏、状态、时间、控制、设置和调试按需显示；鼠标离开隐藏，点击残留焦点也不例外；键盘 Tab 可访问，Escape 可退出 |
| 默认窄而高 | 由 440 × 600 改为 760 × 192 横条，默认前后上下文和当前句，隐藏控件不改变字幕区域布局 |

## 透明度边界

页内可透出网页内容；Document PiP 的原生窗口没有桌面透明 API。本版本在 PiP 内明确禁用背景透明度调节并解释原因，避免旧版滑块看似存在却没有桌面透明效果。浏览器原生标题栏不可隐藏。原生透明悬浮窗是不同技术路线，没有偷偷添加本机程序或系统权限。

## 验证

`node --test tests/*.test.js`：23 项通过，0 失败。`node tests/render-ui.cjs`：真实离线浏览器渲染检查通过。

使用本机 Chrome 的独立临时资料目录离线渲染，测试后关闭浏览器并清理该目录。没有复用用户登录态，没有访问外部网站。

- 默认 760 × 192，工具条 opacity=0，页面启动器隐藏。
- 真实鼠标移入后工具条 opacity=1。
- 真实鼠标打开设置后面板保持显示；离开后面板和按钮全部隐藏。
- 背景透明度从 85% 改成 100% 后背景 alpha=0，刷新仍保持。
- 375px 视口下字幕条宽 343px，工具条无横向溢出。
- 字幕自动滚动不滚动父网页。
- 单元测试覆盖上下文高亮、播放控制、点击跳转、鼠标/键盘状态、偏好保存和 PiP 尺寸/透明度提示。
