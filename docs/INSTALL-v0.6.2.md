# v0.6.2 安装入口修复

修复 Windows 双击一键安装器出现乱码、命令截断、桌面助手无法登记的问题。

- CMD 入口使用 ASCII 内容和 CRLF 换行，启动后切换到 UTF-8 输出。通过自身文件名定位同名 PowerShell 脚本，支持中文及带空格的解压路径。
- 中文 PowerShell 脚本统一使用 UTF-8 BOM，供 Windows PowerShell 5 正确解析。
- 保留批处理的实际退出码；登记失败时不显示成功，不启动浏览器。
- 支持从 Program Files (x86) 查找 Edge；浏览器打开失败时明确提示手动操作，已完成的助手登记仍有效。
- Git 保留 CMD 文件的 CRLF 字节，供 GitHub 源码 ZIP 与本地解压包直接执行。

验证使用真实 cmd.exe 和 Windows PowerShell 5，在中文带空格的临时目录启动实际批处理，分别以 936、437、65001 代码页进入。中文成功提示、两项宿主登记、Chrome/Edge 扩展管理页参数及退出码均通过检查。坏公钥失败和浏览器启动失败也已覆盖。

测试仅模拟注册表写入和浏览器启动，没有更改用户系统登记或连接登录浏览器。安装完成后的实际 B站播放连接仍应在用户使用的扩展目录复验。

更新：关闭桌面字幕窗口，完整解压新版到长期使用目录，重新加载该目录中的扩展，运行新版一键安装器，再刷新 B站页面并点击桌面置顶。
