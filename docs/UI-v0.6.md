# v0.6：字幕可读性与免 ID 安装

## 已完成

- 延续杂志／报告配色，所有字幕均有贴文字底色。当前句与上下文的正文、底色一致，仅当前句带赭红下划线。
- 底色逐行包住文字，长句完整换行，句尾空白继续透明；连续文本与逐句换行均支持。原生底色统一绘制，相邻文字内衬重叠不会重复加深。
- 「窗口透明度」和「字幕底色」独立调整、保存、双向同步。新安装默认窗口100%透明、字幕底色90%不透明；升级保留已有窗口透明度偏好。复杂背景可以把字幕底色提高至100%。
- 鼠标移出后控件不占位；拖动、缩放、倍速面板、设置滚动及点击跳转保留。
- 固定扩展公钥，安装脚本自动计算 ID；双击 native/Install.cmd 即可登记，无需手工复制粘贴。兼容本项目旧配置中最多两个合法旧 ID，不扫描浏览器资料。
- 根目录新增 `一键安装器.cmd`：自动登记助手并打开 Chrome / Edge 扩展管理页；新用户可先打开 `请先看教程-一键安装与使用.html`，按四步完成加载。

没有添加桌面毛玻璃。当前采用可确定对比度的局部底色，避免整块窗口遮挡背景。透明置顶仍需随包的 Windows 原生助手，免 ID 不等于免本地组件。

## 已实测验证

- JavaScript 全套42项测试通过，包含字幕、播放器、原生消息白名单、外观同步及一键安装器测试。
- Windows PowerShell 5 安装器测试通过：无交互输入、路径无关的固定 ID、坏公钥在写入前失败、旧 ID 严格过滤。注册表操作被模拟，没有执行真实系统登记。
- 独立无账号 Chrome 离线渲染通过：当前与普通句底色均为90%，文字颜色一致，仅当前句下划线；192px窗高下，字幕区域悬停117px、移开恢复180px。字号18降到14的样本可见句数由18增加到30。
- 原生窗口离屏自测与协议回环通过：90%底色像素 alpha=230，50%为128，空白为1；普通、当前、DOM字幕都有底色，句尾空白透明，底色重叠不加深。当前句可容纳时完整进入视口；超长句从开头显示，可手动滚动阅读。
- 原生拖动缩放、倍速、连续／逐句排版、设置面板与消息协议的回归检查通过。

## 更新与真机检查

1. 关闭旧桌面字幕窗口，更新完整目录；在扩展管理页重新加载扩展。
2. 双击 native/Install.cmd 更新登记，刷新 B站视频页，再打开「桌面置顶」。如果旧开发者实例仍无法连接，移除后重新加载原文件夹，再运行安装脚本。
3. 将窗口透明度设为100%、字幕底色设为90%或100%；检查浅深背景下所有字幕可读，只有当前句加下划线，空白透明。
4. 鼠标移开后检查全框用于字幕；拖动缩放，切换连续／逐句排版，检查长句与点击跳转。
5. 验证播放暂停、快进退和倍速；保留视频页并在后台播放60秒，核对字幕同步。整页切集会关闭桌面窗，需要在新页再次打开。

假设：继续使用 Windows＋Chrome／Edge，允许一次性安装随包助手；不增加毛玻璃、翻译或额外平台支持。
