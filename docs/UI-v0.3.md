# v0.3 交互与阅读改进

延续 ui-ux-pro-max 的 Minimalism & Swiss Style，重点改为文字对比度、连续阅读和直接拖拽。纯 JS/CSS，无新依赖或权限。

## 已实现

- 页内顶部拖动、四边四角缩放；边界限制在可见视口内，位置尺寸保存。方向键可微调，设置支持宽高输入与重置。
- 删除普通小窗。Document PiP 提供明确的「回到页内」按钮，先移回字幕节点再关闭窗口；原生窗口移动/缩放仍由系统标题栏和边框负责。
- 默认 760 × 192、18px、95% 背景透明；浅色深字 / 深色浅字可选，所有控制继续按需显示。
- 默认连续文本，保留逐句换行选项。每句仍有自己的时间范围、点击跳转与高亮；不会改变字幕数据。
- 长句全文换行；超出视口时从句首显示。滚轮阅读会暂停跟随，点击「跟随播放」恢复，不使用伪逐字时间轴。

## 已实测验证：独立无账号 Chrome，离线假字幕

`node --test tests/*.test.js`：25 项通过。`node tests/render-ui.cjs`：真实 Chromium 渲染与 Input 鼠标事件验证通过。

- 鼠标拖动由 (496, 504) 移至 (316, 324)。
- 右下角缩放由 760 × 192 改为 840 × 262；刷新后恢复位置和尺寸。
- 默认空闲工具栏 opacity=0，移入后为1；设置离开隐藏。
- 默认背景 alpha=0.05，设为100%透明后 alpha=0，刷新保留。
- 同一字幕框、同一批短句：18px 可见11句，14px可见17句（含边缘部分可见句；数量随文本长度变化）。
- 连续文本多句共用一行；20行超长句保留全文并从开头对齐。
- 滚轮阅读后切换当前句不抢滚动；恢复跟随按钮有效。
- 375px 视口内工具栏不横向溢出。

证据：`evidence/ui-v3-checks.json` 和 `evidence/ui-v3-*.png`。截图使用假数据；浅深配色应搭配相应明暗底图，高透明度无法保证任何复杂底图上的对比度。

## 已有模拟测试，但本轮未做 B 站真机复验

PiP 节点移回、关闭与几何恢复已用模拟窗口验证。新版真实 PiP 返回、跨应用置顶、后台同步尚未在用户已登录浏览器重新验收；不把离线检查等同于这些项目通过。

PiP 无桌面透底 API，透明度仅用于页内。默认新偏好键不继承 v0.2 外观，以应用本次要求的新默认值；后续改动会保存。历史报告保留，不覆盖旧版验证事实。
