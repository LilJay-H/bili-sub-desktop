# v0.7 全局字幕与播放进度

## 使用变化

- 字幕仅在原生透明置顶窗口显示，打开视频页自动启动。关闭后网页保留重开按钮及安装错误提示。
- 时间位于顶部正中，加粗14px。浅色主题为深青绿，深色主题为亮青绿。
- 顶栏24px；底部控制与进度共34px。192px窗口的悬停字幕区为128px，空闲字幕区为187px。
- 鼠标移入后可以点击或拖动进度条；顶部时间预览目标位置，松手发送一次跳转。后台时间更新不覆盖拖动预览。
- 鼠标移开后，最底部保留2px进度细线，不保留控制栏占位。
- 点击字幕区后，空格切换播放状态，左右键按步长快退快进。空格长按不反复切换；外观控件和进度条使用自己的键盘操作。
- 快进步长移到桌面外观设置，原外观偏好继续沿用。

## 验证

JavaScript测试覆盖全局自动启动、关闭后手动重开、失败提示与重试、偏好迁移与步长保存、视频总时长传递、进度跳转及边界、未知时长处理。

WPF离屏自测覆盖时间几何居中、加粗、控制栏高度、空闲进度宽度、拖动期间状态更新、松手跳转、取消与越界、切视频取消拖动、未知时长禁用、字幕区空格与左右键事件、步长回传、360px窄窗。

独立无账号Chrome验证启动入口默认隐藏、失败提示、真实鼠标点击重试及375px布局。原生协议回环测试通过。

证据在 `evidence/v0.7.0/native-v7-checks.json`、`native-v7-*.png`、`launcher-checks.json`。图片使用假字幕、仅渲染测试窗口；没有连接用户登录浏览器，本轮未重新完成真实B站后台60秒验证。
