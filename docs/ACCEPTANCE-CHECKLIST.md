# 本地手动验收清单

> **v0.4 起改用 Windows 原生透明窗口。当前验证结果与验收步骤见 [UI-v0.7.md](UI-v0.7.md)。下面保留旧版 PiP 方案的历史验收流程，不适用于新版桌面模式。**

> v0.3：以下「字幕置顶 ↗」对应鼠标移入后的「桌面置顶」按钮；设置入口为滑杆图标「外观设置」。默认 760 × 192、18px、95% 透明、连续文本；页内可拖动和八方向缩放。普通小窗已删除，PiP 有「回到页内」按钮。透明度只在页内可用，PiP 不支持桌面透底。新版离线验证见 `UI-v0.3.md`。

这是一份待执行的验收步骤，不是已通过的真机报告。离线单元测试通过不代表 B 站接口、Document PiP、跨应用置顶或后台同步已验证。请将每项的实际结果与证据填在文末表格中。

## 1. 安装并打开测试视频

1. 使用 Windows 上较新的 Chrome 或 Edge（扩展最低要求 Chromium 116；具体 Document PiP 支持仍需本机实测）。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启扩展页面的「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择含 `manifest.json` 的项目根文件夹，即 `C:\Users\kk\Documents\ChatGPT\B站字幕全局显示`，不要选择 `content` 子文件夹。
5. 确认扩展卡片没有错误。更新代码后，先点扩展卡片的「重新加载」，再刷新 B 站视频页。
6. 打开用户提供的测试视频 `https://www.bilibili.com/zh-Hans/video/BV1XNtJ6UEmm/`。如果它不可用或没有可读字幕，另选一个自己能够正常播放且有字幕的视频。该链接尚未被确认为某一字幕类型的验收样本。
7. 在 B 站播放器里正常播放，并开启播放器字幕。观察右下角「字幕置顶」按钮和歌词卡。

安装页面与开发者模式请由用户自己操作。本清单不授权自动化接受权限提示。遇到验证码、登录失效或权限弹窗，先停止测试并处理原因，不尝试绕过。

## 2. 先记录调试信息

展开歌词卡底部的「外观、快进设置与调试」。记录以下字段即可，不复制整个控制台、Network 导出文件或请求头。

| 字段 | 应观察到的内容 |
| --- | --- |
| 来源 | `api`、`intercept` 或 `dom`；等待状态不是通过 |
| 字幕条数 | 完整字幕应大于 0；`dom` 降级可以是 0 |
| 时间 | 跟随实际视频进度，暂停时不应持续增加 |
| 命中 | 当前字幕的从 0 开始索引；字幕间隔显示「—」是正常情况 |
| 窗口 | 页内或 Document PiP |

需要日志证据时，仅保留以 `[bili-sub]` 开头的业务日志，例如 `ready`、`overlay-cues`、`overlay-window`。不要保存登录凭证、完整字幕签名地址或其他扩展/网页的日志。截图先确认画面中没有无关的敏感内容。

## 3. M1：完整字幕与当前句

1. 在有字幕的视频中，等待加载完成。
2. 确认来源为 `api` 或 `intercept`、条数大于 0；歌词卡中能看到多句上下文。
3. 连续观察至少 3 句：当前句应出现所选主题的高亮标记，并自动滚到可见区域。
4. 检查一处停顿：当前时间落在字幕间隔时不应一直高亮上一句。
5. 分别用 UP 主字幕和只有 AI 字幕的视频执行以上步骤。记录实际语言与来源，不把一次 AI 字幕通过当作 UP 主字幕也通过。

如果只能看到当前一句且来源为 `dom`，记录为「当前句降级可用，完整上下文未通过」。保持 B 站播放器字幕开启，避免把播放器字幕关闭误判为扩展故障。

## 4. M2：置顶窗口与生命周期

1. 用真实鼠标亲自点击歌词卡的「桌面置顶 ↗」或右下角「字幕置顶 ↗」。不要在控制台调用 `.click()` 代替这一步。
2. 确认出现独立的小窗口，调试区显示 `Document PiP · 浏览器置顶窗`。
3. 在视频继续播放时观察 3 句字幕，确认小窗口仍实时更新并滚动。
4. 关闭小窗口，确认歌词卡回到视频页，且仍可控制播放；再次点击置顶应能重新打开。
5. 刷新视频页，确认旧小窗口关闭，新页面出现启动按钮。刷新后需要重新亲自点击置顶，属于已声明限制。
6. 如浏览器不支持 PiP，应显示说明并保留页内字幕；不会打开普通小窗。此时跨应用置顶未通过。
7. 点击「回到页内」，确认字幕框恢复到进入置顶前的位置和尺寸。拖页内顶部移动、拖边框缩放，刷新后确认位置与尺寸保存。

**跨应用置顶由用户手动验收。** 本项目的自动化边界只允许操作 B 站相关页面，不允许读取或截图其他应用。请用户自行准备一个不含敏感内容的其他应用窗口，切到前台，确认字幕小窗仍在最上层。若要保存整屏截图，也由用户自己完成，并确认没有私人信息。没有执行此步骤时，报告必须保留「跨应用置顶未验证」。

## 5. 后台连续播放 60 秒

1. 将倍速设为 `1×`，记录歌词卡中的时间 `T0`、当前字幕和命中索引。
2. 保持 Document PiP 开启，视频正常播放。由用户手动把其他应用切到前台，使 B 站浏览器处于后台。
3. 持续观察小窗 60 秒，期间不要暂停、拖动进度或手动切回视频页。
4. 确认这 60 秒内字幕持续更新，而不是返回浏览器时才集中刷新。
5. 记录结束时间 `T1`、当前句和命中索引。正常无缓冲时，`T1 - T0` 应约为 60 秒；若发生缓冲，应记录并重新选择稳定时段测试。
6. 回到视频页，比较播放器进度及当前字幕与小窗是否一致。记录观察到的误差，建议目标不超过 1 秒。

只在前台等待 60 秒或只比较起止数字，不能充分证明后台字幕持续同步。此项同样需要用户手动完成跨应用部分。

## 6. M3：基础播放控制

1. 点击「暂停」，确认视频与字幕时间一起停止；点击「播放」恢复。
2. 在视频中间点击 `+10s` 和 `−10s`，确认时间变化约为 10 秒，字幕跳到对应位置。
3. 在设置中把「快进退」改为 `5`，重复操作，确认按钮文字和实际跳转均为 5 秒。
4. 切换 `1.5×`，确认视频播放速度变化，字幕仍按视频时间同步；测试后恢复 `1×`。
5. 在视频开头快退不应出现负时间；在结尾快进不应越过视频时长。

## 7. M4：分 P、合集和切视频

1. 打开一个至少有两段的分 P 视频。在中间分 P 测试「上一集」「下一集」，确认前往的是相邻分 P。
2. 打开一个至少有两集的合集，在中间集测试上一集/下一集，确认不是推荐区的无关视频。
3. 每次切换后检查字幕已清空并重新载入，条数、当前时间和内容属于新视频，不能残留上一集。
4. 在列表首尾检查边界提示，不应跳到无关视频。
5. 在 B 站页面手动切到另一集或另一分 P，再观察字幕是否自动更新，覆盖页面单页切换路径。

当前控制按钮采用普通视频链接导航以提高可预测性。整页导航会关闭 PiP；新视频的字幕重新加载后，需再次亲自点击置顶。不能把「必须重新点置顶」隐瞒为无缝切集已实现。如果页面的合集结构识别失败，界面应提示回 B 站页面手动切集，并验证手动切换后的字幕更新。

## 8. M5：字幕跳转与外观

1. 点击一条不在当前播放位置的字幕，确认跳到该句开始时间。
2. 调整字号，确认内容和控制按钮可读、没有被裁切。
3. 调整背景滑块，确认卡片背景发生变化，文字仍清晰。
4. 缩放 PiP 窗口，确认字幕区域仍可滚动，播放控制仍可使用。
5. 连续排版下缩小字号，应显示更多字幕；长句完整换行，不能以省略号丢弃内容。滚轮阅读长句后播放进度不应抢走滚动位置，点击「跟随播放」恢复。

背景滑块控制的是卡片底色，不提供操作系统级透明窗口、鼠标穿透或完全透明桌面歌词。

## 9. 无字幕、失败提示与凭证边界

1. 打开明确没有字幕的视频，确认出现「此视频没有可用字幕」或当前降级状态的清晰提示，不持续显示上一个视频的字幕。
2. 确认播放控制仍可用，页面没有崩溃。
3. 字幕文件域名不在实测白名单、网络失败或播放器信息未就绪时，应显示可理解的提示，不能静默失败。
4. 若遇登录失效、验证码或权限弹窗，停止；不要为测试主动退出账号，也不要尝试绕过。
5. 检查保存的证据只含字幕状态与时间信息。不要导出凭证、请求头或完整登录网络记录。
