# B 站字幕桌面歌词

把 B 站视频字幕放到桌面上。字幕窗口透明、始终置顶，可以在看视频的同时处理其他事情。

## 功能

- 显示当前字幕，并保留前后文，播放时自动跟随。
- 支持 B 站 UP 主字幕和 AI 自动生成字幕。
- 桌面窗口透明置顶，可拖动位置、调整大小。
- 播放 / 暂停、快进、快退、倍速、上一集、下一集。
- 点击字幕跳转到对应时间。
- 调整字号、窗口透明度、字幕底色和配色。
- 连续文本、逐句换行两种排版方式。
- 鼠标移开后，控制栏隐藏，字幕占满整个窗口。
- 长句自动换行，完整显示字幕内容。

## 使用环境

- Windows
- Chrome 或 Edge
- Manifest V3 扩展
- B 站视频页面

## 安装

请先打开根目录的 [请先看教程-一键安装与使用.html](请先看教程-一键安装与使用.html)，里面有图示流程。

1. 解压完整压缩包，并把文件夹放到准备长期保留的位置。
2. 双击根目录的 **一键安装器.cmd**。
3. 在打开的 Chrome 或 Edge 扩展管理页开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目文件夹。
5. 刷新 B 站视频页，点击页面中的「桌面置顶」。

安装器会自动登记透明桌面助手，不需要填写扩展 ID，也不需要手动运行桌面程序。

> 浏览器首次加载本地扩展时，需要用户在扩展管理页点击一次「加载已解压的扩展程序」。

## 日常使用

打开有字幕的视频后，点击页面里的「桌面置顶」。桌面窗口会自动显示当前字幕，并跟随播放进度更新。

鼠标移入窗口后会出现控制栏，鼠标移开后控制栏隐藏，整个窗口恢复为字幕区域。窗口顶部可以拖动，边框和四角可以调整大小。

### 播放控制

| 控件 | 作用 |
| --- | --- |
| 播放 / 暂停 | 控制 B 站视频播放状态 |
| `−10s` / `+10s` | 快退或快进，步长可以在页内设置 |
| 倍速 | 选择 0.25× 至 4× 播放速度 |
| 上一集 / 下一集 | 切换合集或分P中的相邻视频 |
| 点击字幕 | 跳转到该句开始时间 |
| 页内 | 关闭桌面窗口，回到网页字幕 |

### 外观设置

- **窗口透明度**：调整字幕窗口空白区域的透明程度。
- **字幕底色**：调整文字背后的底色，复杂背景下可以提高到 100%。
- **字号**：字号越小，同样大小的窗口能显示更多行。
- **连续文本**：多句字幕可以紧凑排列。
- **逐句换行**：每句字幕单独换行，更方便按句阅读。
- **配色**：可切换浅色纸张、深色墨色等主题。

当前播放句会用下划线标记，普通字幕与当前字幕保持相同的文字颜色和底色，避免播放时文字跳动。

## 字幕说明

工具会读取 B 站播放器提供的字幕。没有可读取字幕的视频会显示提示；画面中直接烧录的文字不会被转换为字幕。

如果视频刚打开时没有字幕，请先在 B 站播放器中开启 CC/字幕，再刷新页面。

## 更新

1. 关闭正在显示的桌面字幕窗口。
2. 用新版文件夹替换旧文件，或重新解压到新的位置。
3. 在扩展管理页点击「重新加载」。
4. 双击新版根目录的「一键安装器.cmd」。
5. 刷新 B 站视频页。

如果更换了文件夹位置，需要重新运行一次安装器，让桌面助手更新路径。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 桌面窗口没有出现 | 重新运行「一键安装器.cmd」，重新加载扩展并刷新 B 站页面 |
| 提示没有字幕 | 确认播放器中有 CC/字幕；烧录在画面里的文字无法读取 |
| 字幕和背景混在一起 | 提高「字幕底色」到 95% 或 100%，也可以切换配色 |
| 拖动没有反应 | 鼠标移入窗口，拖动顶部区域；调整大小时拖边框或四角 |
| 字幕不再跟随播放 | 点击控制栏里的「跟随播放」 |
| 切换视频后窗口关闭 | 刷新新视频页面后，再点击一次「桌面置顶」 |
| 倍速没有改变 | 等待播放器状态回传后再继续播放；也可以回到网页确认当前倍速 |

## 隐私与权限

扩展只在 B 站视频页面运行，并使用字幕文件所在的 B 站字幕域名。字幕和播放状态通过浏览器与本地桌面窗口传递，桌面助手不需要网络连接。

扩展不需要读取账号 Cookie。登录状态由 B 站页面按正常方式处理。
